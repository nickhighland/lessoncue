# LessonCue brand assets

The files in this directory are derived from the approved LessonCue artwork. The SVG files in `source/` are the canonical masters and should be used whenever the destination supports vectors.

## Approved artwork

- `source/lessoncue-icon.svg` — square calendar-and-play icon with transparency.
- `source/lessoncue-banner.svg` — icon and LessonCue wordmark on the dark brand background.
- `source/lessoncue-wordmark.svg` — transparent horizontal LessonCue lockup.

The primary dark background is `#262F2C`. The icon artwork uses the supplied orange `#D89028`; the supplied banner and wordmark contain their own closely matched orange values and should not be recolored.

## Ready-to-upload store and web files

- `store/google-play-app-icon-512.png` — 512 × 512, 32-bit PNG with alpha.
- `store/google-play-feature-graphic-1024x500.png` — 1024 × 500, opaque PNG.
- `store/android-tv-banner-320x180.png` — 320 × 180 Android TV banner with the app name.
- `store/fire-tv-banner-1280x720.png` — 1280 × 720 Fire TV artwork.
- `web/lessoncue-icon-512.png` — high-resolution web and directory icon.
- `web/social-card-1600x900.png` — social/link-preview image.

Android launcher, Android TV banner, browser/PWA, GitHub Pages, README, tvOS app-icon stack, and tvOS top-shelf resources are generated from these masters and checked into their platform directories. Keep the masters unchanged and regenerate the derivatives when the artwork changes.
