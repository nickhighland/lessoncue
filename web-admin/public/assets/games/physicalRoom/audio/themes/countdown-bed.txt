countdown-bed.mp3 — Physical Room
=================================

ROLE
  Looping bed while a timed window is open.

REPLACE THIS FILE
  Delete this .txt and drop in "countdown-bed.mp3" in the same folder. The name must
  match exactly. Nothing else needs to change — no code, no config.

WHEN IT PLAYS
  Replaces the gameplay bed for as long as players have a clock running --
  answering, voting, or a prompt window. Returns to the gameplay bed when
  the window closes.

SUGGESTED CHARACTER
  urgent but not frantic: a pulse that makes the clock feel real.

SPEC
  20-60 s, seamlessly loopable, mixed low (plays at 0.28 gain).

IF THIS FILE IS ABSENT
  Lookup cascades preset → engine → shared. If this file is absent,
  LessonCue tries assets/games/shared/audio/themes/countdown-bed.mp3, and if that is
  also absent, no music plays for this cue. LessonCue synthesizes effects but not
  music, so an absent bed or sting simply means silence. That is the shipped
  default and is not an error.

LICENSING

  licence/permission record, and an attribution entry before release. See
  docs/activities-assets-and-sound.md.
