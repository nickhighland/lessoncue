countdown-announce.mp3 — Rapid Fire
===================================

ROLE
  One-shot as a timed window opens.

REPLACE THIS FILE
  Delete this .txt and drop in "countdown-announce.mp3" in the same folder. The name must
  match exactly. Nothing else needs to change — no code, no config.

WHEN IT PLAYS
  Plays once at the moment a clock starts. This is the place for an
  announcer: "Thirty seconds -- starting now."

SUGGESTED CHARACTER
  a short spoken or stung announcement.

SPEC
  under 3 s, played over the bed (0.5 gain).

IF THIS FILE IS ABSENT
  Lookup cascades preset → engine → shared. If this file is absent,
  LessonCue tries assets/games/shared/audio/themes/countdown-announce.mp3, and if that is
  also absent, no music plays for this cue. LessonCue synthesizes effects but not
  music, so an absent bed or sting simply means silence. That is the shipped
  default and is not an error.

LICENSING

  licence/permission record, and an attribution entry before release. See
  docs/activities-assets-and-sound.md.
