ui-btn-select.mp3 — Creative Response (Punchline)
=================================================

ROLE
  Tap / press.

REPLACE THIS FILE
  Delete this .txt and drop in "ui-btn-select.mp3" in the same folder. The name must
  match exactly. Nothing else needs to change — no code, no config.

WHEN IT PLAYS
  The workhorse. Plays on pointer-down for every control on the participant
  phone — choice buttons, tool buttons, palette swatches, everything. Also
  plays on keyboard activation.

  Played many times in quick succession, so it is pitch-randomized between
  0.85x and 1.15x on every press to stop rapid taps sounding machine-gunned.
  Author it dry and neutral; the randomizer supplies the variation.

SUGGESTED CHARACTER
  comedy-club warmth: loose, playful, a little cabaret.

SPEC
  ≤120 ms, dry, minimal tail — a long tail will smear under fast tapping.

PITCH
  Randomized 0.85x–1.15x on every play. Author one dry take.

COVERS
  The 20 named games built on the punchline engine — Creative Response
  (Punchline):
    Punchline, Caption This, Autocomplete, Bad Advice, Wrong Answers Only,
    Slogan Factory, Movie Pitch, Make It Worse, Explain It Badly, Rename It,
    New Product, Headline, Deleted Scene, Alternate Ending, Plot Twist, Excuse
    Generator, Superpower / Catch, Explain This Photo, Who Approved This?,
    Worst Ranking

  …and any activity a teacher builds on this engine from blank.

DOES NOT COVER
  Games on the other 27 engines. They use their own engine pack when it
  supplies this cue, and otherwise
  assets/games/shared/audio/sfx/ui-btn-select.mp3.

  One named game can also override this file on its own by adding
  assets/games/<presetId>/audio/sfx/ui-btn-select.mp3; everything it omits
  keeps falling through to this pack.

IF THIS FILE IS ABSENT
  Lookup cascades preset → engine → shared. If this file is absent, LessonCue
  tries assets/games/shared/audio/sfx/ui-btn-select.mp3, and if that is also
  absent, LessonCue plays its original synthesized cue from
  web-admin/src/activities/effects.ts. That is the shipped default.
