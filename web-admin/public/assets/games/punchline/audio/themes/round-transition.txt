round-transition.mp3 — Creative Response (Punchline)
====================================================

ROLE
  One-shot round change.

REPLACE THIS FILE
  Delete this .txt and drop in "round-transition.mp3" in the same folder. The name must
  match exactly. Nothing else needs to change — no code, no config.

WHEN IT PLAYS
  Fires once, on the TV/projector, when the game enters a round-intro phase.
  Marks the seam between rounds so the room knows to look up again.

SUGGESTED CHARACTER
  comedy-club warmth: loose, playful, a little cabaret.

SPEC
  1–3 s, one-shot, should not upstage the opening sting.

COVERS
  The 20 named games built on the punchline engine — Creative Response
  (Punchline):
    Punchline, Caption This, Autocomplete, Bad Advice, Wrong Answers Only,
    Slogan Factory, Movie Pitch, Make It Worse, Explain It Badly, Rename It,
    New Product, Headline, Deleted Scene, Alternate Ending, Plot Twist, Excuse
    Generator, Superpower / Catch, Explain This Photo, Who Approved This?,
    Worst Ranking

  …and any activity a teacher builds on this engine from blank.

DOES NOT COVER
  Games on the other 27 engines. They use their own engine pack when it
  supplies this cue, and otherwise
  assets/games/shared/audio/themes/round-transition.mp3.

  One named game can also override this file on its own by adding
  assets/games/<presetId>/audio/themes/round-transition.mp3; everything it
  omits keeps falling through to this pack.

IF THIS FILE IS ABSENT
  Lookup cascades preset → engine → shared. If this file is absent, LessonCue
  tries assets/games/shared/audio/themes/round-transition.mp3, and if that is
  also absent, no music plays for this cue. LessonCue synthesizes effects but
  not music, so an absent bed or sting simply means silence. That is the
  shipped default and is not an error.

LICENSING

  docs/activities-assets-and-sound.md.
