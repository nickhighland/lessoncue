intro-theme.mp3 — Ordering, Matching & Sorting
==============================================

ROLE
  Looping lobby bed.

REPLACE THIS FILE
  Delete this .txt and drop in "intro-theme.mp3" in the same folder. The name must
  match exactly. Nothing else needs to change — no code, no config.

WHEN IT PLAYS
  Loops on the TV/projector while the join code is on screen and players are
  arriving. Stops the moment the host starts the game.

  This is the only theme cue that repeats. It should sit happily under
  conversation for several minutes without becoming irritating.

SUGGESTED CHARACTER
  tidy and mechanical — pieces clicking into their slots.

SPEC
  30–90 s, seamlessly loopable, mixed low (plays at 0.4 gain).

COVERS
  The 10 named games built on the ordering engine — Ordering, Matching &
  Sorting:
    Order Up, Timeline, Rank It, Verse Scramble, Missing Step, Cause & Effect,
    Sorting Hat, Odd One Out, Match-Up, Connections

  …and any activity a teacher builds on this engine from blank.

DOES NOT COVER
  Games on the other 27 engines. They use their own engine pack when it
  supplies this cue, and otherwise
  assets/games/shared/audio/themes/intro-theme.mp3.

  One named game can also override this file on its own by adding
  assets/games/<presetId>/audio/themes/intro-theme.mp3; everything it omits
  keeps falling through to this pack.

IF THIS FILE IS ABSENT
  Lookup cascades preset → engine → shared. If this file is absent, LessonCue
  tries assets/games/shared/audio/themes/intro-theme.mp3, and if that is also
  absent, no music plays for this cue. LessonCue synthesizes effects but not
  music, so an absent bed or sting simply means silence. That is the shipped
  default and is not an error.
