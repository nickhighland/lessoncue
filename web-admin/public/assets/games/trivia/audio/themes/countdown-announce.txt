countdown-announce.mp3 — Quiz & Answer (Trivia)
===============================================

ROLE
  One-shot as a timed window opens.

REPLACE THIS FILE
  Delete this .txt and drop in "countdown-announce.mp3" in the same folder. The name must
  match exactly. Nothing else needs to change — no code, no config.

WHEN IT PLAYS
  Plays once at the moment a clock starts. This is the place for an
  announcer: "Thirty seconds -- starting now."

SUGGESTED CHARACTER
  a short spoken or stung announcement.

SPEC
  under 3 s, played over the bed (0.5 gain).

COVERS
  The 22 named games built on the trivia engine — Quiz & Answer (Trivia):
    Trivia, Fact or Fiction, Two Truths & a Lie, Spot the Fake, Finish the
    Quote, Fill the Blank, Higher or Lower, Guess the Number, Is It a Horse?,
    Who Said It?, Which Lesson?, Recap Race, Key Word, Before or After, Which
    Came First?, Over / Under, Closest Without Going Over, The Price Is Wrong,
    Definitely Real, That Can’t Be Right, Wager Trivia, Survivor Trivia

  …and any activity a teacher builds on this engine from blank.

DOES NOT COVER
  Games on the other 27 engines. They use their own engine pack when it
  supplies this cue, and otherwise
  assets/games/shared/audio/themes/countdown-announce.mp3.

  One named game can also override this file on its own by adding
  assets/games/<presetId>/audio/themes/countdown-announce.mp3; everything it
  omits keeps falling through to this pack.

IF THIS FILE IS ABSENT
  Lookup cascades preset → engine → shared. If this file is absent, LessonCue
  tries assets/games/shared/audio/themes/countdown-announce.mp3, and if that
  is also absent, no music plays for this cue. LessonCue synthesizes effects
  but not music, so an absent bed or sting simply means silence. That is the
  shipped default and is not an error.
