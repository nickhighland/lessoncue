ui-btn-lock-in.mp3 — Quiz & Answer (Trivia)
===========================================

ROLE
  Final submission.

REPLACE THIS FILE
  Delete this .txt and drop in "ui-btn-lock-in.mp3" in the same folder. The name must
  match exactly. Nothing else needs to change — no code, no config.

WHEN IT PLAYS
  Plays on top of the tap sound when a press actually commits something: an
  answer, a vote, a drawing, a buzz, joining the game. Deliberately heavier
  than ui-btn-select so committing feels different from browsing.

  Not pitch-randomized — a submission should sound the same every time.

SUGGESTED CHARACTER
  measured quiz-show poise: clean, confident, lightly brassy, never frantic.

SPEC
  150–400 ms, weighty, with a low-end thud under the click.

PITCH
  Played at its authored pitch.

COVERS
  The 22 named games built on the trivia engine — Quiz & Answer (Trivia):
    Trivia, Fact or Fiction, Two Truths & a Lie, Spot the Fake, Finish the
    Quote, Fill the Blank, Higher or Lower, Guess the Number, Is It a Horse?,
    Who Said It?, Which Lesson?, Recap Race, Key Word, Before or After, Which
    Came First?, Over / Under, Closest Without Going Over, The Price Is Wrong,
    Definitely Real, That Can’t Be Right, Wager Trivia, Survivor Trivia

  …and any activity a teacher builds on this engine from blank.

DOES NOT COVER
  Games on the other 27 engines. They use their own engine pack when it
  supplies this cue, and otherwise
  assets/games/shared/audio/sfx/ui-btn-lock-in.mp3.

  One named game can also override this file on its own by adding
  assets/games/<presetId>/audio/sfx/ui-btn-lock-in.mp3; everything it omits
  keeps falling through to this pack.

IF THIS FILE IS ABSENT
  Lookup cascades preset → engine → shared. If this file is absent, LessonCue
  tries assets/games/shared/audio/sfx/ui-btn-lock-in.mp3, and if that is also
  absent, LessonCue plays its original synthesized cue from
  web-admin/src/activities/effects.ts. That is the shipped default.
