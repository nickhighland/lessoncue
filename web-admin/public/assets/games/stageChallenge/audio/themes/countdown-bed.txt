countdown-bed.mp3 — Host-Judged Stage Challenge
===============================================

ROLE
  Looping bed while a timed window is open.

REPLACE THIS FILE
  Delete this .txt and drop in "countdown-bed.mp3" in the same folder. The name must
  match exactly. Nothing else needs to change — no code, no config.

WHEN IT PLAYS
  Replaces the gameplay bed for as long as players have a clock running --
  answering, voting, or a prompt window. Returns to the gameplay bed when
  the window closes.

SUGGESTED CHARACTER
  urgent but not frantic: a pulse that makes the clock feel real.

SPEC
  20-60 s, seamlessly loopable, mixed low (plays at 0.28 gain).

COVERS
  The 11 named games built on the stageChallenge engine — Host-Judged Stage
  Challenge:
    Beat the Clock, Minute to Win It, Teach It Back, Best Explanation,
    Scenario Judge, Example / Non-Example, Unnecessary Debate, Courtroom, Sell
    Me This, Pose Match, Photo Hunt

  …and any activity a teacher builds on this engine from blank.

DOES NOT COVER
  Games on the other 27 engines. They use their own engine pack when it
  supplies this cue, and otherwise
  assets/games/shared/audio/themes/countdown-bed.mp3.

  One named game can also override this file on its own by adding
  assets/games/<presetId>/audio/themes/countdown-bed.mp3; everything it omits
  keeps falling through to this pack.

IF THIS FILE IS ABSENT
  Lookup cascades preset → engine → shared. If this file is absent, LessonCue
  tries assets/games/shared/audio/themes/countdown-bed.mp3, and if that is
  also absent, no music plays for this cue. LessonCue synthesizes effects but
  not music, so an absent bed or sting simply means silence. That is the
  shipped default and is not an error.
