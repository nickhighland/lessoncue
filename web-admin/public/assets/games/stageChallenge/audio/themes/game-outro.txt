game-outro.mp3 — Host-Judged Stage Challenge
============================================

ROLE
  One-shot closing sting.

REPLACE THIS FILE
  Delete this .txt and drop in "game-outro.mp3" in the same folder. The name must
  match exactly. Nothing else needs to change — no code, no config.

WHEN IT PLAYS
  Fires once, on the TV/projector, when the game reaches its final results or
  the run ends. The counterpart to game-intro: it closes the show before the
  lesson resumes.

SUGGESTED CHARACTER
  spotlight theatre: drum-tight, expectant, a live audience in the room.

SPEC
  2–6 s, one-shot, resolves — the room should feel the game is over.

COVERS
  The 11 named games built on the stageChallenge engine — Host-Judged Stage
  Challenge:
    Beat the Clock, Minute to Win It, Teach It Back, Best Explanation,
    Scenario Judge, Example / Non-Example, Unnecessary Debate, Courtroom, Sell
    Me This, Pose Match, Photo Hunt

  …and any activity a teacher builds on this engine from blank.

DOES NOT COVER
  Games on the other 27 engines. They use their own engine pack when it
  supplies this cue, and otherwise
  assets/games/shared/audio/themes/game-outro.mp3.

  One named game can also override this file on its own by adding
  assets/games/<presetId>/audio/themes/game-outro.mp3; everything it omits
  keeps falling through to this pack.

IF THIS FILE IS ABSENT
  Lookup cascades preset → engine → shared. If this file is absent, LessonCue
  tries assets/games/shared/audio/themes/game-outro.mp3, and if that is also
  absent, no music plays for this cue. LessonCue synthesizes effects but not
  music, so an absent bed or sting simply means silence. That is the shipped
  default and is not an error.

LICENSING

  docs/activities-assets-and-sound.md.
