game-timer-alarm.mp3 — Host-Judged Stage Challenge
==================================================

ROLE
  Time's up.

REPLACE THIS FILE
  Delete this .txt and drop in "game-timer-alarm.mp3" in the same folder. The name must
  match exactly. Nothing else needs to change — no code, no config.

WHEN IT PLAYS
  Plays once on the participant phone when the response window reaches zero.
  The window closing is decided by the server, not by this sound.

SUGGESTED CHARACTER
  spotlight theatre: drum-tight, expectant, a live audience in the room.

SPEC
  0.5–1.5 s, unmistakable, but not punishing — players lose rounds to this.

PITCH
  Played at its authored pitch.

COVERS
  The 11 named games built on the stageChallenge engine — Host-Judged Stage
  Challenge:
    Beat the Clock, Minute to Win It, Teach It Back, Best Explanation,
    Scenario Judge, Example / Non-Example, Unnecessary Debate, Courtroom, Sell
    Me This, Pose Match, Photo Hunt

  …and any activity a teacher builds on this engine from blank.

DOES NOT COVER
  Games on the other 27 engines. They use their own engine pack when it
  supplies this cue, and otherwise
  assets/games/shared/audio/sfx/game-timer-alarm.mp3.

  One named game can also override this file on its own by adding
  assets/games/<presetId>/audio/sfx/game-timer-alarm.mp3; everything it omits
  keeps falling through to this pack.

IF THIS FILE IS ABSENT
  Lookup cascades preset → engine → shared. If this file is absent, LessonCue
  tries assets/games/shared/audio/sfx/game-timer-alarm.mp3, and if that is
  also absent, LessonCue plays its original synthesized cue from
  web-admin/src/activities/effects.ts. That is the shipped default.

LICENSING
  Any audio committed here is a bundled asset and needs a source note, a
  licence/permission record, and an attribution entry before release. See
  docs/activities-assets-and-sound.md.
