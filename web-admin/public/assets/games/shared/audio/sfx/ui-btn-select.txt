ui-btn-select.mp3 — Shared fallback pack
========================================

ROLE
  Tap / press.

REPLACE THIS FILE
  Delete this .txt and drop in "ui-btn-select.mp3" in the same folder. The name must
  match exactly. Nothing else needs to change — no code, no config.

WHEN IT PLAYS
  The workhorse. Plays on pointer-down for every control on the participant
  phone — choice buttons, tool buttons, palette swatches, everything. Also
  plays on keyboard activation.

  Played many times in quick succession, so it is pitch-randomized between
  0.85x and 1.15x on every press to stop rapid taps sounding machine-gunned.
  Author it dry and neutral; the randomizer supplies the variation.

SUGGESTED CHARACTER
  neutral house style — this pack is the safety net every game falls back to, so keep it characterful but not tied to any one format.

SPEC
  ≤120 ms, dry, minimal tail — a long tail will smear under fast tapping.

PITCH
  Randomized 0.85x–1.15x on every play. Author one dry take.

COVERS
  Every game on every engine — all 162 named games in the catalogue, plus
  anything a teacher builds from blank — except where a more specific pack
  supplies its own sfx/ui-btn-select.mp3. This is the only pack consulted for
  every activity in LessonCue, so it is the one to author first.

DOES NOT COVER
  Nothing. No engine or preset pack supplies its own sfx/ui-btn-select.mp3, so
  every game in LessonCue reaches this file for this cue.

IF THIS FILE IS ABSENT
  This is the last folder searched. If the file is missing here too, LessonCue
  plays its original synthesized cue from web-admin/src/activities/effects.ts.
  That is the shipped default.

LICENSING
  Any audio committed here is a bundled asset and needs a source note, a
  licence/permission record, and an attribution entry before release. See
  docs/activities-assets-and-sound.md.
