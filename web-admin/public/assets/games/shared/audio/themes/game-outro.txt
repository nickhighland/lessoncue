game-outro.mp3 — Shared fallback pack
=====================================

ROLE
  One-shot closing sting.

REPLACE THIS FILE
  Delete this .txt and drop in "game-outro.mp3" in the same folder. The name must
  match exactly. Nothing else needs to change — no code, no config.

WHEN IT PLAYS
  Fires once, on the TV/projector, when the game reaches its final results or
  the run ends. The counterpart to game-intro: it closes the show before the
  lesson resumes.

SUGGESTED CHARACTER
  neutral house style — this pack is the safety net every game falls back to, so keep it characterful but not tied to any one format.

SPEC
  2–6 s, one-shot, resolves — the room should feel the game is over.

COVERS
  Every game on every engine — all 162 named games in the catalogue, plus
  anything a teacher builds from blank — except where a more specific pack
  supplies its own themes/game-outro.mp3. This is the only pack consulted for
  every activity in LessonCue, so it is the one to author first.

DOES NOT COVER
  Nothing. No engine or preset pack supplies its own themes/game-outro.mp3, so
  every game in LessonCue reaches this file for this cue.

IF THIS FILE IS ABSENT
  This is the last folder searched. If the file is missing here too, no music
  plays for this cue. LessonCue synthesizes effects but not music, so an
  absent bed or sting simply means silence. That is the shipped default and is
  not an error.

LICENSING
  Any audio committed here is a bundled asset and needs a source note, a
  licence/permission record, and an attribution entry before release. See
  docs/activities-assets-and-sound.md.
