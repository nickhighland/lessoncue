countdown-final-five.mp3 — Shared fallback pack
===============================================

ROLE
  One-shot for the last five seconds.

REPLACE THIS FILE
  Delete this .txt and drop in "countdown-final-five.mp3" in the same folder. The name must
  match exactly. Nothing else needs to change — no code, no config.

WHEN IT PLAYS
  Starts once as the clock crosses five seconds remaining, which is what a
  recorded "five, four, three, two, one" needs.

  It fires on the way down and never restarts while it is playing. A
  window shorter than five seconds never crosses the mark from above, so
  this cue stays silent there rather than finishing after the game has
  moved on.

SUGGESTED CHARACTER
  a spoken count, or five rising ticks.

SPEC
  about 5 s, and no longer -- it should land on zero. Played over the bed (0.5 gain).

COVERS
  Every game on every engine — all 162 named games in the catalogue, plus
  anything a teacher builds from blank — except where a more specific pack
  supplies its own themes/countdown-final-five.mp3. This is the only pack
  consulted for every activity in LessonCue, so it is the one to author first.

DOES NOT COVER
  Nothing. No engine or preset pack supplies its own
  themes/countdown-final-five.mp3, so every game in LessonCue reaches this
  file for this cue.

IF THIS FILE IS ABSENT
  This is the last folder searched. If the file is missing here too, no music
  plays for this cue. LessonCue synthesizes effects but not music, so an
  absent bed or sting simply means silence. That is the shipped default and is
  not an error.

LICENSING
  Any audio committed here is a bundled asset and needs a source note, a
  licence/permission record, and an attribution entry before release. See
  docs/activities-assets-and-sound.md.
