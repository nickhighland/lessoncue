gameplay-bed.mp3 — Shared fallback pack
=======================================

ROLE
  Looping bed under ordinary play.

REPLACE THIS FILE
  Delete this .txt and drop in "gameplay-bed.mp3" in the same folder. The name must
  match exactly. Nothing else needs to change — no code, no config.

WHEN IT PLAYS
  Loops quietly from the moment the game starts until it finishes,
  underneath questions, answers and reveals. It steps aside for the
  countdown bed during a timed window and returns afterwards.

  Until this cue existed nothing played during a round at all: every
  sting stopped the one piece of music there was.

SUGGESTED CHARACTER
  steady and unobtrusive: something a room can talk over for a whole game.

SPEC
  60-180 s, seamlessly loopable, mixed low (plays at 0.28 gain).

COVERS
  Every game on every engine — all 162 named games in the catalogue, plus
  anything a teacher builds from blank — except where a more specific pack
  supplies its own themes/gameplay-bed.mp3. This is the only pack consulted
  for every activity in LessonCue, so it is the one to author first.

DOES NOT COVER
  Nothing. No engine or preset pack supplies its own themes/gameplay-bed.mp3,
  so every game in LessonCue reaches this file for this cue.

IF THIS FILE IS ABSENT
  This is the last folder searched. If the file is missing here too, no music
  plays for this cue. LessonCue synthesizes effects but not music, so an
  absent bed or sting simply means silence. That is the shipped default and is
  not an error.

LICENSING
  Any audio committed here is a bundled asset and needs a source note, a
  licence/permission record, and an attribution entry before release. See
  docs/activities-assets-and-sound.md.
