fx-confetti-pop.mp3 — Word & Category
=====================================

ROLE
  Celebration burst.

REPLACE THIS FILE
  Delete this .txt and drop in "fx-confetti-pop.mp3" in the same folder. The name must
  match exactly. Nothing else needs to change — no code, no config.

WHEN IT PLAYS
  Accompanies a win, a correct reveal, or a podium celebration.

SUGGESTED CHARACTER
  light and typographic: keys, chimes, small bright taps.

SPEC
  0.3–1 s, bright, upward.

PITCH
  Randomized 0.85x–1.15x on every play. Author one dry take.

COVERS
  The 8 named games built on the word engine — Word & Category:
    Category Blitz, Name Five, Alphabet Challenge, Last One Standing, Chain
    Reaction, Word Association, Word Storm, One Word Too Far

  …and any activity a teacher builds on this engine from blank.

DOES NOT COVER
  Games on the other 27 engines. They use their own engine pack when it
  supplies this cue, and otherwise
  assets/games/shared/audio/sfx/fx-confetti-pop.mp3.

  One named game can also override this file on its own by adding
  assets/games/<presetId>/audio/sfx/fx-confetti-pop.mp3; everything it omits
  keeps falling through to this pack.

IF THIS FILE IS ABSENT
  Lookup cascades preset → engine → shared. If this file is absent, LessonCue
  tries assets/games/shared/audio/sfx/fx-confetti-pop.mp3, and if that is also
  absent, LessonCue plays its original synthesized cue from
  web-admin/src/activities/effects.ts. That is the shipped default.

LICENSING
  Any audio committed here is a bundled asset and needs a source note, a
  licence/permission record, and an attribution entry before release. See
  docs/activities-assets-and-sound.md.
