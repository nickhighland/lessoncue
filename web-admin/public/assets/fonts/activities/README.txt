Activity fonts
==============

The activity/game UI bundles these supplied fonts:

- Fredoka-Variable.ttf — Fredoka variable font, used for questions, answers,
  instructions, controls, and player names. License: SIL Open Font License 1.1;
  see Fredoka-OFL.txt.
- LuckiestGuy-Regular.ttf — Luckiest Guy, used for game titles, round/status
  callouts, score values, reveals, and winner emphasis. License: Apache License
  2.0; see LuckiestGuy-Apache-2.0.txt.

These font assets are used only by the Activity/game surfaces. The supplied
Fredoka notice is SIL OFL 1.1; Luckiest Guy's supplied notice is Apache 2.0.
